# 🏭 الدليل التشغيلي التفصيلي للشاشات (Functional Module Specification)

يقدم هذا الملف التوثيق الوظيفي والتقني الدقيق لكل شاشة ووحدة في نظام **CIOB GMAO Light UI Excel**، مع توضيح الفلسفة التشغيلية والمنطق البرمجي والأعمدة المتوافقة مع إكسيل.

---

## 📊 1. لوحة التحكم والقيادة (DashboardView)
- **المسار في الكود:** `src/presentation/pages/dashboard/DashboardView.jsx`
- **الهدف الصناعي:** إعطاء مدير الصيانة والمسؤولين نظرة فورية شاملة على صحة المصنع وحالة المخزون دون الحاجة لتصفح الجداول الطويلة.
- **المكونات الأساسية:**
  - **شريط المؤشرات الحيوية (Top KPI Cards):**
    - إجمالي مراجع قطع الغيار (`Total Articles`).
    - القيمة المالية الإجمالية للمخزون بالدرهم/اليورو.
    - عدد المواد التي بلغت حد الطلب (`Alertes`).
    - عدد المواد التي نفدت بالكامل (`Ruptures`).
  - **مخطط حركات المخزون الشهرية:** رسم بياني تحليلي يوضح تباين الصرف على الصيانة العلاجية والوقائية.
  - **شريط الوصول السريع:** أزرار ثلاثية الأبعاد سريعة لإنشاء حركة صرف، توريد جديد، أو فحص آلة.

## 📦 2. إدارة مخزون قطع الغيار (StockView)
- **المسار في الكود:** `src/presentation/pages/stock/StockView.jsx`
- **ورقة إكسيل المتطابقة:** `Stock_Actuel`
- **الأعمدة الرئيسية:**
  | العمود | الوصف باللغة العربية | المعادلة البرمجية في إكسيل |
  | :--- | :--- | :--- |
  | `N°` | رقم السطر التسلسلي | فهرس الصفحة من 1 إلى 20 |
  | `REF` | المرجع الفريد للمقال | نصي (كود المقال، مثال: `ROUL-6204`) |
  | `Désignation` | اسم المقال وتوصيفه الفني | نصي |
  | `Type` | نوع وتصنيف المقال | مرتبط بجدول `Types` |
  | `Diagnostic` | رمز التشخيص المرجعي | مرتبط بجدول `Diagnostics` |
  | `Stock Initial` | المخزون الافتتاحي في بداية الدورة | رقم موجب |
  | `Entrées` | مجموع الكميات الواردة | `=SUMIFS(Mouvement[Quantite], Mouvement[Ref], [@Ref], Mouvement[Type], "Entrée")` |
  | `Sorties` | مجموع الكميات المنصرفة | `=SUMIFS(Mouvement[Quantite], Mouvement[Ref], [@Ref], Mouvement[Type], "Sortie")` |
  | `Stock Actuel` | الرصيد الفعلي الحالي | `=[@[Stock Initial]] + [@Entrées] - [@Sorties]` |
  | `Seuil` | حد الأمان وتنبيه الطلب | رقم محدد مسبقاً |
  | `Alerte` | الحالة اللحظية للرصيد | `OK` (أخضر), `ALERTE` (أصفر), `RUPTURE` (أحمر) |
  | `Emplacement` | موقع التخزين في المستودع | مثال: `R1-B04` |
- **أنواع المقالات والقطع (TypeView):**
  - **المسار في الكود:** `src/presentation/pages/referentiel/TypeView.jsx`
  - **ورقة إكسيل:** `Types` (الأنواع الرئيسية لمواد الـ PDR مثل Foret, Vis, Roulement).
  - **التطويرات المعمارية:** تثبيت صف عناوين الأعمدة (`sticky top-0 z-10 bg-slate-100 shadow-2xs`) مع الفرز التفاعلي للأسهم عبر النقر، وتطبيق كبسولة الإجراءات الموحدة `3-Dots Action Popover Card` مع زر الإجراء السريع النقي بدون نص (`Pure Icon Light UI`) وعنوان العمود الصريح `•••`.
- **تسميات وتوصيف المقالات (DesignationView):**
  - **المسار في الكود:** `src/presentation/pages/referentiel/DesignationView.jsx`
  - **ورقة إكسيل:** `Diagnostics / Designations` (التسميات الفنية لقطع الـ PDR).
  - **التطويرات المعمارية:** تثبيت رأس الجدول والفرز المتزامن وتطبيق كبسولة الإجراءات الموحدة `3-Dots Action Popover Card` مع زر الوصول السريع للمخزون النقي بدون نص (`Pure Icon Light UI`) وعنوان العمود الصريح `•••`.

## ⚡ 3. حركات المخزون والصرف السريع (SortieRapideView)
- **المسار في الكود:** `src/presentation/pages/movements/SortieRapideView.jsx`
- **ورقة إكسيل المتطابقة:** `Mouvement`
- **التدفقات الـ 5 المعتمدة (The 5 Fluxes):**
  1. **صيانة تصحيحية (Action Corrective):** عطل طارئ، يستلزم اختيار الآلة والفني المتدخل وتحديد سبب العطل.
  2. **صيانة وقائية (Action Préventive):** أعمال صيانة دورية، تستلزم اختيار الآلة ونوع العملية المخططة.
  3. **صيانة تحسينية (Action Améliorative):** ترقية أو تعديل على خط إنتاج.
  4. **استهلاك عام (Usage Interne):** استهلاك مباشر لا يرتبط بآلة، مع تحديد المستفيد (`Technicien`, `Opérateur`, `Chef`).
  5. **إعادة تزويد (Réapprovisionnement - Entrée):** إدخال شحنة جديدة إلى المخزون، يستلزم اسم المورد ورقم الوصل والموقع.
- **التفريق بين القائم بالعملية والمستلم:**
  - `Intervenant`: الفني الذي نفذ التدخل في الورشة.
  - `Demandeur`: المشغل أو المسؤول الذي طلب القطعة للاستعمال الشخصي.
- **جدول سجل الحركات الموحد (MouvementsJournalTable):**
  - **ثبات رأس الجدول (Sticky Table Header):** تم تثبيت صف عناوين الأعمدة في الأعلى (`sticky top-0 z-10 bg-slate-100 shadow-2xs`) ليبقى ظاهراً بشكل دائم أثناء التمرير العمودي لأسطر سجل الحركات.
  - **بطاقة الإجراءات ثلاثية النقاط (3-Dots Action Popover Card):** تم ترقية عمود الإجراءات (`Action`) بإضافة كبسولة تفاعلية تضم زر الطباعة السريعة `Bon A4` وزر `MoreVertical` (`•••`) ينبثق منه بطاقة خيارات أنيقة وعالية التنسيق تتضمن طباعة الوصل المعتمد A4، التعديل الفوري، والحذف الإداري.

## 🏗️ 4. إدارة الآلات والمسؤولين (MachinesRegisteredView)
- **المسار في الكود:** `src/presentation/pages/machines/MachinesRegisteredView.jsx`
- **ورقة إكسيل المتطابقة:** `Machines_Registered`
- **الحقول والأعمدة:**
  - `id_machine_registered`: المعرف الفريد للآلة (`MCH-01`, `CNC-02`).
  - `designation`: اسم الآلة.
  - `id_family`: عائلة الآلة (مرتبط بـ `Families`).
  - `id_templates`: نموذج الآلة (مرتبط بـ `Templates`).
  - `id_zone_default`: المنطقة الافتراضية للتواجد (مرتبط بـ `Zones`).
  - `technician`: الفني المكلّف بالصيانة الدورية.
  - `status`: حالة التشغيل الحالية (`En service`, `En maintenance`, `Arrêt`).

## 🛠️ 5. بنية المكونات وقطع المستودع (Composants & Entrepot)
- **مبدأ الهرم الرباعي الصارم (Architecture 4 Niveaux):**
  - **المستوى 1: مجموعات المكونات (`CompGroupView.jsx`):** الصنف التكنولوجي العام (مثل `MOTEUR`, `REDUCTEUR`, `POMPE`, `VARIATEUR`).
  - **المستوى 2: عائلات المكونات (`CompFamilyView.jsx`):** المبدأ التقني الدقيق (مثل `Moteur Triphasé`, `Monophasé`, `Servo`).
  - **المستوى 3: نماذج وقوالب المكونات (`CompTemplateView.jsx`):** بطاقة المواصفات المعيارية والقدرات والسرعات (مثل `MOT-3PH-40KW-1430`).
  - **المستوى 4: قطع المستودع المادية (`EntrepotView.jsx`):** القطعة الفعلية المادية في الرف برقم السيريال والحالة الفنية.
- **مبدأ الفصل التام:**
  - هذه الشاشات مخصصة **حصراً** للمكونات الميكانيكية والكهربائية المركبة (`Warehouse Components & Items`) وتعتمد على جداول منفصلة تماماً (`Comp_Groups`, `Comp_Families`, `Comp_Templates`, `Part_Types`, `Part_Designations`).
  - يُمنع الخلط بينها وبين قطع غيار الـ PDR الاستهلاكية في جدول المخزون العام (`Stock_Actuel`).
- **فلسفة الترقيم الثلاثي:**
  - `ID`: الهوية الرقمية للنظام (Passport ID، غير قابل للتغيير).
  - `CODE`: الكود البشري المختصر للمصنع ولوحات التشغيل (Plant Code).
  - `REF`: مرجع الصانع والكتالوج التجاري للمشتريات (Manufacturer P/N).
- **التفاصيل الموسعة:** راجع الدليل المرجعي الخاص [`docs/COMPOSANTS_HIERARCHIE_ET_IDENTIFIANTS.md`](./COMPOSANTS_HIERARCHIE_ET_IDENTIFIANTS.md).
