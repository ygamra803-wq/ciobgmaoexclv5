# 👥 توثيق صفحة المستخدمين والأدوار (Utilisateurs & Profils View)
## نظام CIOB GMAO Light UI Excel

هذا الملف يوثق بالتفصيل المعماري والتقني صفحة **Utilisateurs & Profils**، والتي تجمع بين أوراق عمل `Technicians` و `Operations` (المشغلين ورؤساء الفرق).

---

## 🏛️ 1. الفلسفة والهدف الوظيفي (Functional Philosophy)
- **إدارة الموارد البشرية للصيانة والإنتاج (Maintenance & Operations Personnel):** تسجيل وتصنيف جميع الأفراد العاملين في المنشأة لضمان تتبع دقيق لكل حركة ومسؤولية صرف.
- **التفريق المعماري بين الفئات:**
  1. **التقني / المنفذ (`Technicien / Intervenant`):** الفني القائم بأعمال التركيب، الصيانة، أو الفك.
  2. **رئيس الفريق (`Chef d'équipe`):** المسؤول الميداني الطالب أو المشرف على الأعمال.
  3. **المشغل (`Opérateur`):** مشغل الآلة أو خط الإنتاج.

---

## 📊 2. التطابق مع أعمدة إكسيل (Excel Twin Mapping)

### أ. جدول الفنيين (`Technicians`)
| العمود في إكسيل | اسم الحقل البرمجي | النوع | الوصف |
| :---: | :--- | :---: | :--- |
| **(A)** | `id_technician` | `String` | المعرف التلقائي للفني (مثال: `TECH-01`, `TECH-02`). |
| **(B)** | `nom` | `String` | الاسم الكامل للفني. |
| **(C)** | `id_zone` | `String` | المنطقة أو الورشة الرئيسية التابع لها. |
| **(D)** | `specialite` | `String` | التخصص المهني (ميكانيك، كهرباء، أوتوماتيزم...). |

### ب. جدول العمليات والمشرفين (`Operations`)
| العمود في إكسيل | اسم الحقل البرمجي | النوع | الوصف |
| :---: | :--- | :---: | :--- |
| **(A)** | `id_operation` | `String` | المعرف التلقائي (`OP-01...` للمشغلين أو `CHEF-01...` لرؤساء الفرق). |
| **(B)** | `nom` | `String` | اسم المشغل أو رئيس الفريق أو وصف العملية. |
| **(C)** | `id_zone` | `String` | منطقة العمل الميدانية. |
| **(D)** | `type_profil` | `String` | نوع الحساب (`OPERATEUR` أو `CHEF`). |

---

## ⚡ 3. معايير النافذة المنبثقة الموحدة (`AddUserModal`)
- تبديل سريع بين 3 فئات (`TECHNICIEN`, `CHEF`, `OPERATEUR`) عبر شريط تبويب مدمج أنيق.
- توليد تلقائي للمعرفات (`getNextId`) بحسب الصيغة الدقيقة لمعادلات إكسيل.
- إمكانية إضافة منطقة جديدة أثناء إنشاء المستخدم دون فقدان البيانات المدخلة.
