## **⚠️ قائمة المشاكل المتبقية (1,827 خطأ)**

### **🔴 1. أخطاء Property Does Not Exist (TS2339) - 1,120 خطأ**
**شدة: حرجة (Critical)**

هذه هي أكثر الأخطاء شيوعًا. المشكلة الرئيسية هي أن العديد من الكلاسات لا تحتوي على تعريفات properties في TypeScript.

#### **أ. كلاسات بدون تعريف properties**

**ملف: `src/core/database/DatabaseService.ts` (32 خطأ)**
```typescript
export class DatabaseService {
  constructor(_dbPath = './data/gmao.db') {
    // ... 
    this.isBrowser = typeof window !== 'undefined';  // ❌ Property not defined
    this.db = null;                                    // ❌ Property not defined
    this.indexedDB = indexedDBService;                // ❌ Property not defined
  }
  // ...
}
```

**الحل:**
```typescript
export class DatabaseService {
  isBrowser: boolean;
  db: any;
  indexedDB: any;

  constructor(_dbPath = './data/gmao.db') {
    this.isBrowser = typeof window !== 'undefined';
    this.db = null;
    this.indexedDB = indexedDBService;
  }
}
```

**ملف: `src/application/services/SparePartApplicationService.ts` (11 خطأ)**

### **🟡 2. أخطاء Expected X Arguments, But Got Y (TS2554) - 177 خطأ**
**شدة: عالية (High)**

هذه الأخطاء تحدث عندما لا تتطابق عدد معلمات الدالة مع عدد الوسيطات.

**ملف: `src/core/cache/CacheService.tsx` (7 أخطاء)**
```typescript
// في تعريف الدالة
get<T>(key: string): T | null;

// في الاستخدام
cacheService.get();  // ❌ Expected 1 argument, but got 0
```

**الحل:**
```typescript
// تأكد من تمرير جميع المعلمات المطلوبة
cacheService.get('myKey');
```

**ملف: `src/core/cache/MultiLevelCacheManager.ts` (2 خطأ)**
```typescript
// في تعريف الدالة
set<T>(key: string, value: T, ttl?: number): void;

// في الاستخدام
cacheManager.set(key, value, ttl, options);  // ❌ Expected 2-3 arguments, but got 4
```

**الحل:**
```typescript
// إما تعديل التعريف أو الاستخدام
cacheManager.set(key, value, ttl);  // إزالة options
// أو
set<T>(key: string, value: T, ttl?: number, options?: any): void;
```

## **💡 التوصيات الفورية**

### **1. إصلاح كلاسات بدون properties**
```typescript
// قبل
class MyClass {
  constructor(data) {
    this.property = data.property;
  }
}

// بعد
class MyClass {
  property: string;

  constructor(data: { property: string }) {
    this.property = data.property;
  }
}
```

### **2. تحديد types لل hooks**
```typescript
// قبل
export function useMyHook(props = {}) {
  const { a, b, c } = props;
}

// بعد
interface MyHookProps {
  a: string;
  b: number;
  c: boolean;
}

export function useMyHook(props: MyHookProps = { a: '', b: 0, c: false }) {
  const { a, b, c } = props;
}
```

### **3. إزالة `any` من types**
```typescript
// قبل
export interface MyState {
  items: any[];
}

// بعد
export interface MyItem {
  id: string;
  name: string;
}

export interface MyState {
  items: MyItem[];
}
```

### **4. استخدام interfaces بدلاً من any**
```typescript
// قبل
function processData(data: any) {
  return data.value;
}

// بعد
interface MyData {
  value: string;
}

function processData(data: MyData) {
  return data.value;
}
```
