# Scripts Directory

هذا المجلد يحتوي على أدوات التشغيل والأرشفة لمشروع CIOB GMAO:

- **`tools/`**: الأدوات المساعدة النشطة (مثل مولد أيقونات الـ PWA `generate_icons.js`).
- **`archive/`**: سكريبتات الترحيل والتحديثات والإصلاحات السابقة المؤرشفة للاطلاع والمراجعة إن لزم الأمر، دون التأثير على نظافة جذر المشروع.
